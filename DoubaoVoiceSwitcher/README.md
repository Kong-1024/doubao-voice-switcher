# 豆包语音切换器（右 Alt 单击开关）

日常保持**微信输入法**；单击物理键盘的**右 Alt**启动豆包语音，讲话完毕后再次单击**右 Alt**，结束识别、提交文字并自动恢复微信输入法。

## 使用方法

| 当前状态 | 操作 | 结果 |
|---|---|---|
| 微信输入法、语音未开启 | 单击右 Alt | 自动切到豆包并打开语音条 |
| 豆包语音识别中 | 再次单击右 Alt | 结束并提交文字，然后恢复微信输入法 |
| 启动中或识别中 | 按 Esc | 取消语音并恢复微信输入法 |

右 Alt 的按下和松开都会被本工具拦截，不会触发应用菜单。启动/结束由豆包输入法自带的本地 RPC 完成，不依赖豆包的全局长按快捷键。

## 托盘菜单

- **取消语音并恢复微信输入法**：异常时手动复位。
- **开机自动启动**：按需启用；默认不擅自开启。
- **退出**：取消语音、恢复微信输入法并退出工具。

## 配置（settings.json）

- `activationDelayMs`：等待输入法切换完成的最长时间，默认 1500 毫秒。
- `commitDelayMs`：语音条关闭后等待文字提交的时间，默认 1000 毫秒。
- `restoreWhenAnotherKeyStopsVoice`：豆包因其他操作自行关闭语音条时，自动恢复微信输入法。
- `maxListeningSeconds`：最长连续录音时长，默认 60 秒。
- `playSoundFeedback`：语音开始和结束时播放短提示音。
- `cancelOnEsc`：允许 Esc 取消语音。

## 自检

命令行参数 `--rpc-probe` 会自动执行一次“切到豆包 → 打开语音条 → 结束语音 → 恢复微信”的短测试，并把结果写入程序目录的 `test-result.txt`。
